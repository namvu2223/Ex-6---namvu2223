This project's goal is to create a page to display users' data fetched from an API endpoint (https://cg7bzwd7vkkgswhukeoxeg2oku0jbnak.lambda-url.us-east-2.on.aws). The project contains 2 files to operate:

server.js: Handle API call and display logic using Axios
index.ejs: Handle frontend of the page to displat data
To run the project:

Open Terminal ⇒ Navigate to the project directory ⇒ Type "npm install" ⇒ Type "node server.js" ⇒ Go to "http://localhost:3000" in browser
